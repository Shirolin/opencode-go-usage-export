# OpenCode Go 利用状況エクスポート

![License](https://img.shields.io/github/license/Shirolin/opencode-go-usage-export) ![Version](https://img.shields.io/badge/version-5.10.0-3fb950.svg) ![Tampermonkey](https://img.shields.io/badge/Tampermonkey-userscript-00485b.svg)

[OpenCode コンソール](https://opencode.ai) の Usage ページから Go サブスクリプションの利用統計をエクスポートする Tampermonkey ユーザースクリプトです。token の内訳（cache read / reasoning）や、モデル / API キー / プラン / 日付ごとの集計に対応し、CSV + Excel エクスポートが可能です。

## 機能

- **ネットワーク層キャプチャ**: コンソールのサーバーリクエストを傍受・再送して生 JSON を直接取得（正確なタイムスタンプ、keyID、プランを含む）。DOM スクレイピングより数十倍高速
- **階層ストレージ（IndexedDB）**: 明細は直近 30 日のみ保持し、それより古いデータは「日付 × モデル × プラン × key」で集計して長期保存。無制限に肥大化しない
- **全件 / 差分取得**: 差分は正確なタイムスタンプで早期終了し、新しいリクエストだけを取得
- **途中再開**: ページごとに保存するため、中断しても続きから再開可能
- **順次ページ取得 + リトライ**: 既定 350ms 間隔、失敗時は自動リトライ、停止検知で無限ループを防止
- **自動同期**: 最終同期から 6 時間以上経過してページを開くと自動で差分取得（ファイルはダウンロードしない）。設定でオン/オフ可能
- **ページ内統計パネル**: 合計、直近 30 日コスト、Go 利用上限の比較（5h/$12 · 7d/$30 · 30d/$60）、モデル / key / プラン別のバーチャート
- **大画面モード**: 中央のダイアログ（720px）で統計や内訳を見やすく
- **設定パネル**: 表示モード、自動同期、エクスポート既定値、パネル折りたたみ、取得間隔、ランキング件数など
- **API キー名**: キー名を手動更新し、パネルとエクスポートで分かりやすいラベルを表示
- **エクスポート**: 日付範囲フィルタ付きの手動 CSV / Excel エクスポート
- **キャッシュ自動クリーンアップ**: 30 日間アクセスのない古い workspace レコードを自動削除

## セキュリティ注意

> **このスクリプトは公式リポジトリからのみ入手してください**: <https://github.com/Shirolin/opencode-go-usage-export>（公開・オープンソース・監査可能）。

このスクリプトは OpenCode のバックエンド API に直接アクセスします（ログインセッションや API キー関連データを含む）。Tampermonkey のインストールページではスクリプトの全コードが表示されます。**インストール前に入手元を確認してください**。出所不明の改変版は API キーや利用データ、アカウントセッションを窃取する恐れがあります。

- 初回パネル表示時に一度だけセキュリティ注意を表示（閉じると再表示されません）。設定欄の下部に常時ソースのリマインダーを表示
- バージョンの確認: Tampermonkey 内のスクリプトの `@version` と、このリポジトリの最新バージョンを比較してください

## インストール

1. ブラウザに Tampermonkey をインストール
2. 新規スクリプトを作成し、[opencode-go-usage-export.user.js](./opencode-go-usage-export.user.js) の内容を貼り付けて保存
3. `https://opencode.ai/workspace/<workspace-id>/usage` を開く（ログイン必須）
4. 右下の **Go** ボタンでパネルを開く

## 使い方

| ボタン / 機能 | 動作 |
|---|---|
| 全件取得 | 最初から全ページを取得し、マージ・重複排除してキャッシュに保存 |
| 差分取得 | 新しいリクエストのみ取得（早期終了）、マージ・重複排除 |
| 再読み込み | キャッシュから統計パネルを再描画 |
| Key名を再取得 | API キーエンドポイントからキー名を取得してキャッシュ |
| CSV / Excel で保存 | 選択した日付範囲を手動エクスポート |
| データ削除 | 現在の workspace キャッシュを削除 |
| ⤢ 広い表示 | コンパクトドロワー / 中央ダイアログを切り替え |
| ⚙ 設定 | 設定エリアを展開（表示、同期、エクスポートなど） |

データソース: ネットワーク層の生 JSON（`source=network`）を優先。傍受に失敗した場合は DOM スクレイピング（`source=dom`、低速、keyID/プランなし）に自動でフォールバックします。

## 設定項目

`localStorage`（`oc-go-export-settings-v1`）に保存されます:

- **表示モード**: コンパクト（右下ドロワー）/ ワイド（中央ダイアログ）
- **外側クリックで閉じる**: オン / オフ
- **自動同期**: 6 時間以上経過で差分取得
- **既定のエクスポート期間**: 直近7日 / 直近30日 / 全期間
- **初期展開するセクション**: 概要、内訳、エクスポート
- **詳細設定**: 取得間隔（250/350/500ms）、モデル / key のランキング件数

## データ保存

- IndexedDB: データベース `oc-go-usage-export-v5`、テーブル `workspaces`（workspace ID をキーに保存）
- 明細（detail）: 直近 30 日の生リクエスト
- 集計（summary）: ウィンドウ外データの集計、長期保存
- keyNames: API キー ID → 表示名のマッピング

## 注意事項

- コンソールの**非公開**内部 API に依存しています。コンソールの変更でいつでも動作しなくなる可能性があり、その場合は DOM スクレイピングに自動フォールバックします
- パネルの利用上限比較はキャッシュ済み明細（直近 30 日）のみに基づくもので、公式データではありません
- 正確な監査が必要な場合は、定期的に手動「全件取得」を行い、ダウンロードした CSV を保存してください
